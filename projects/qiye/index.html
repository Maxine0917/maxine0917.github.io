为什么做栖页

查资料时，标签栏里混着正在用的网页、准备读的内容和已经处理过的页面。留着会越积越多，关掉又怕忘记；忙完之后，还说不清时间花在了哪里。

栖页把已打开的网页、稍后阅读清单和浏览统计放进 Chrome 新标签页：按网站找回原页，把没空读的链接收好，再查看时间花在哪些网站上。保存不会关闭原标签，点开链接不会自动标记已读；网站限制和暂停记录都由用户主动开启。

把整理放进新标签页

标签开多了，标题挤在一起，找一篇刚看过的资料要来回翻。栖页把已打开的网页列在新标签页，按网站分组，点标题就能回到原来的那一页。

  • 新标签页就是入口。点击浏览器「＋」，查看已打开的网页。
  • 按网站找回原页。同一网站的网页排在一起；点标题切回原标签，跨窗口也能跳转。
  • 关掉重复，留住原页。可关闭单个标签、重复网址或同一网站的整组标签；清理重复时保留最早打开的一页。

新建标签页 → 按网站整理 → 切回原网页

播放失败，可以重试或直接查看录屏。

读没读完，由用户确认

看到一篇想读的文章，没时间细看，关掉怕忘，留着又挤占标签栏。栖页提供「稍后查看」清单，先保存链接，读完再勾选移入「已查看」。

  • 保存链接，原页保留。保存不会关闭原标签；没有保存记录时，侧栏自动收起。
  • 打开不等于读完。打开保存的链接不会自动标记「已查看」，读完后由用户勾选。
  • 刷新不丢，另开一页也能看。同一 Chrome 个人资料中打开的栖页共享两份清单：刷新后仍在，一页保存或勾选，其他栖页页面也会更新。两份清单都支持搜索。

保存网页 → 稍后查看 → 勾选已查看

播放失败，可以重试或直接查看录屏。

专注限制由用户选择

工作中顺手打开别的网站，倒计时还在走，注意力已经被带走。栖页可在专注期间只允许访问预先选定的网站，也支持单独计时。

  • 只计时，不拦截。未勾选「限制网站访问」时，倒计时不会拦截网页。
  • 勾选后再限制访问。先保存允许访问的网站，再勾选限制；本次专注期间按这份列表放行。
  • 临时任务可以放行。遇到临时需要的网站，可仅为本次专注放行该域名，也可直接结束专注。

设置允许网站 → 开始专注 → 访问限制

播放失败，可以重试或直接查看录屏。

打开录屏

看清时间花在哪

一天打开了不少网页，却说不清时间花在哪。栖页按网站统计浏览时长，支持按今天、本周、本月、今年回看；不想记录时，可以暂停计时。

  • 按网站和周期查看。切换今天、本周、本月、今年，查看累计浏览时长和网站排行。
  • 导出后继续分析。支持导出 JSON / CSV；记录和设置保存在本机，无需注册。
  • 暂停一段时间。选择暂停时长，到时自动恢复，也可提前恢复。暂停的是栖页计时，Chrome 浏览历史仍会保留。

切换时间范围 → 查看网站排行与浏览时长
